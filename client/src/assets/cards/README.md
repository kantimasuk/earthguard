# รูปการ์ดของทีม (ไม่บังคับ)

วางรูปการ์ดไว้ในโฟลเดอร์นี้ เกมจะใช้รูปแทนการ์ดที่วาดด้วยโค้ดให้อัตโนมัติ (ไม่ต้องแก้โค้ด)
การ์ดใบไหนไม่มีรูป เกมจะใช้แบบที่วาดเองเหมือนเดิม → ทยอยใส่ทีละใบได้

## ตั้งชื่อไฟล์

- **ชื่อไฟล์ = รหัสแบบการ์ด** ในคอลัมน์แรกของตารางด้านล่าง เช่น `R-AIR-A.webp`, `A-INF-1-A.png`, `T-HEAT.jpg`
  การ์ดที่มีหลายใบแต่หน้าตาเหมือนกัน (เช่น กิจกรรม 3 ใบ) ใช้รูปเดียว → ทั้งเกมใช้รูปแค่ **42 รูป**
- **หลังการ์ด** = `back.webp` (หรือ .png/.jpg)
- อยากให้บางใบต่างจากใบอื่นในแบบเดียวกัน → ตั้งชื่อด้วยรหัสรายใบ เช่น `A-INF-1-03.webp` (ใช้ก่อนรหัสแบบ)
- นามสกุลที่รองรับ: `.webp` `.png` `.jpg` `.jpeg` · ตัวพิมพ์เล็ก/ใหญ่ของชื่อต้องตรงกับตาราง

## ขนาดรูปที่แนะนำ

- สัดส่วน **5 : 7** (เช่น **500 × 700 px**) — ถ้าไม่ตรง ระบบจะตัดขอบให้พอดีการ์ดอัตโนมัติ (ตัดตรงกลาง) และทำมุมโค้งให้เอง
- ใช้ **.webp** คุณภาพ ~80 ขนาดไฟล์ละ < 80 KB (ทั้งชุดไม่ควรเกิน ~4 MB เพราะผู้เล่นโหลดผ่านมือถือ)
- ตัวหนังสือบนรูปควรใหญ่พอ — บนโทรศัพท์การ์ดบนโต๊ะกว้างแค่ประมาณ 55–75 px (แตะการ์ดจะเห็นรายละเอียดเต็มในป๊อปอัป)

หลังใส่รูป: ถ้าเปิด `npm run dev` อยู่ ให้รีเฟรชหน้าเว็บ (ถ้ารูปใหม่ไม่ขึ้น ให้หยุดแล้วรัน `npm run dev` ใหม่)
