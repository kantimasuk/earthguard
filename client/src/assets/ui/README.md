# รูปตกแต่ง UI (ไม่บังคับ)

วางไฟล์ในโฟลเดอร์นี้ (`client/src/assets/ui/`) ด้วย **ชื่อตามตาราง** ใช้ได้ทั้ง `.png` `.jpg` `.webp`
ไม่มีไฟล์ไหน ระบบจะใช้หน้าตาเดิมแทน · เพิ่ม/เปลี่ยนรูปแล้วรีเฟรชเบราว์เซอร์ได้เลย (ไม่ต้องแก้โค้ด)

| ชื่อไฟล์ | ใช้ที่ไหน | ขนาดแนะนำ |
|---|---|---|
| `level-easy` | หน้าตั้งค่าเกม การ์ด "ง่าย" (แทนวงกลม 2 วง) | 600×360 พื้นใส (PNG/WebP) |
| `level-medium` | การ์ด "ปานกลาง" (แทน 3 วง) | 600×360 |
| `level-hard` | การ์ด "ยาก" (แทน 4 วง) | 600×360 |
| `ai-leaf` | รูปโปรไฟล์ AI ใบเตย | 256×256 สี่เหลี่ยมจัตุรัส |
| `ai-water` | รูปโปรไฟล์ AI ธารา | 256×256 |
| `ai-mountain` | รูปโปรไฟล์ AI ภูผา | 256×256 |
| `ai-wind` | รูปโปรไฟล์ AI พายุ | 256×256 |
| `phase-1` | ภาพประกาศ "ช่วงที่ 1" ตอนเริ่มเกม | กว้าง ~1200 พื้นใส |
| `phase-2` | ภาพประกาศ "ช่วงที่ 2" (เอฟเฟกต์สีส้ม) | กว้าง ~1200 พื้นใส |
| `phase-3` | ภาพประกาศ "ช่วงที่ 3" (เอฟเฟกต์สีแดง) | กว้าง ~1200 พื้นใส |
| `game-end` | ภาพประกาศ "จบเกม" (เอฟเฟกต์สีแดง) | กว้าง ~1200 พื้นใส |
| `bg-game` | พื้นหลังตั้งแต่เข้าหน้าเล่นเกม (ช่วงที่ 1) | 1920×1080 JPG/WebP |
| `bg-phase-2` | พื้นหลังช่วงที่ 2 | 1920×1080 |
| `bg-phase-3` | พื้นหลังช่วงที่ 3 | 1920×1080 |

พอเกมจบ พื้นหลังจะกลับไปเป็นรูปเดิมของแอป (`client/public/images/background.*`)

เคล็ดลับ: รูปพื้นหลังควรเป็น JPG/WebP ไม่เกิน ~400 KB เพื่อให้มือถือโหลดเร็ว · ภาพประกาศช่วงควรเป็น PNG/WebP พื้นโปร่งใส
